# Power BI Project
# 📊 Sales Performance Analysis Dashboard
• Developed an interactive Power BI dashboard to analyze Sales Performance.
Created KPI cards, multi-dimensional sales visualizations, and dynamic slicers/filters to analyze business performance, and monthly/yearly sales trends.

• I have recently learn this Sales Data Analysis and find meaningful insights and better business decisions. 

• This is my Power BI project which I developed using POWER BI. I used Power BI features such as Power Query for data cleaning and Pivot Table, Pivot Chart.

# 📈 Dashboard Features
**Key Performance Indicators (KPIs):**

Total Sales Target

Total Actual Sales

Sales Variance

Variance Percentage

Number of Months Achieving Sales Targets

# 🛠️ Tools and Technologies
Microsoft Power BI

Power Query for data transformation

DAX for KPI calculations and sales performance measures

Data visualization and dashboard design

Interactive filters, conditional formatting, and sparklines

# 📌 Project Overview
This project focuses on analyzing sales performance using an interactive Power BI dashboard. While learning interactive dashboard design, I explored how to transform sales data into meaningful business insights using KPIs, charts, conditional formatting, and interactive filters.

# 🚀 Project Outcome
Create an interactive dashboard through raw data and this dashboard demonstrates how business data can be transformed into actionable insights to support sales monitoring, performance evaluation, and data-driven decision-making.

# 🔑 Key Insights
**Overall Sales Performance:** Total actual sales are approximately 18.95M, compared with a total sales target of 19M, indicating that actual sales are slightly below the overall target.

**Sales Variance:** The dashboard displays a negative sales variance, highlighting a gap between actual sales and the target that requires attention.

**Monthly Sales Trends:** The monthly clustered column chart compares actual sales with sales targets, helping identify months of strong performance and months where targets were not achieved.

**Target Achievement:** The dashboard indicates that only 2 months achieved their sales targets, highlighting an opportunity to improve monthly sales performance.

**Team-Wise Sales Contribution:** The donut chart shows sales contributions from four teams:

Delish: 5.29M

Jucies: 5.20M

Yummies: 4.65M

Tempo: 3.81M
